# Checklists — EmpathIA

Antes de decir “terminé” o abrir un Pull Request, usa la checklist del sprint.

| Sprint | Carpeta |
|--------|---------|
| 0 | [sprint-0/](./sprint-0/) |
| 1 | [sprint-1/](./sprint-1/) |

## Cómo usarla

1. Completa tu misión.  
2. Marca cada ítem con evidencia real (no “creo que sí”).  
3. Si un ítem falla, la misión sigue abierta.  
4. Lleva la checklist a la revisión de sprint.
