# M0-A — Entorno Unity (Avatar)

## ID

`M0-A-entorno-unity`

## Título

Abrir el entorno del cliente Unity y comprender la estructura

## Rol

A

## Objetivo

Que Unity (o Unity Hub) quede operativo respecto a `cliente-unity/`, que entiendas dónde vivirá el cliente, y que dejes constancia escrita de la estructura — **sin** implementar login ni lip-sync.

## Tiempo estimado

60–120 minutos (Unity puede tardar en instalar/descargar)

## Competencias que desarrolla

- Setup de entorno de juego/cliente  
- Lectura de estructura de carpeta  
- Separación cliente vs servidor  

## Conocimientos previos

- M0-COMUN completada  
- Notion básica de “escena” en videojuegos (se puede aprender en la misión)  

## Entregables

1. Unity Hub instalado (y editor Unity 6 en descarga o instalado)  
2. Proyecto o carpeta de trabajo bajo `cliente-unity/` reconocible  
3. Archivo `cliente-unity/APRENDIZAJE.md` explicando en español: qué es tu rol, qué carpetas no tocas, qué harás en Sprint 1  
4. (Si Unity ya abre) captura o nota: “escena abre” / “proyecto crea”  

## Criterios de aceptación

- [ ] Puedes abrir Unity Hub en tu PC  
- [ ] Sabes la ruta `cliente-unity/`  
- [ ] Existe `cliente-unity/APRENDIZAJE.md` con tus palabras  
- [ ] Explicas por qué A no llama a `inteligencia/` directo  
- [ ] Checklist Sprint 0 A en verde  

## Cómo validar el resultado

1. Mostrar Unity Hub.  
2. Mostrar `cliente-unity/` en el explorador/Cursor.  
3. Abrir `APRENDIZAJE.md` y leer 30 segundos al mentor.  
4. Si el editor aún descarga: documentarlo en APRENDIZAJE (no bloquea el sprint si Hub + doc están OK; el mentor confirma).  

## Errores comunes

| Error | Qué hacer |
|-------|-----------|
| Esperar 2 horas sin documentar | Escribe APRENDIZAJE mientras descarga |
| Crear el proyecto fuera del monorepo | Muévelo / créalo dentro de `cliente-unity/` |
| Empezar login API “porque ya sé” | Eso es Sprint ≥1; aquí solo entorno |

## Qué NO debo hacer

- Conectar al API de B todavía (salvo exploración supervisada)  
- Modificar `servidor/` o `inteligencia/`  
- Pedir morphs definitivos a D sin leer ExpressionPacket
