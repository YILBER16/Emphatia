# M0-COMUN — Repo y herramientas base

## ID

`M0-COMUN-repo-y-herramientas`

## Título

Preparar el entorno común del monorepo

## Rol

COMÚN (los cuatro)

## Objetivo

Tener el repositorio EmpathIA abierto en Cursor, conocer tu carpeta de rol y poder navegar el mapa del proyecto.

## Tiempo estimado

45–90 minutos (según instalación)

## Competencias que desarrolla

- Orientación en monorepo  
- Uso básico de Cursor  
- Disciplina de ownership de carpetas  

## Conocimientos previos

- Uso básico de Windows  
- Saber crear carpetas y abrir programas  

## Entregables

1. Repo EmpathIA accesible en tu PC  
2. Cursor abierto en la raíz del monorepo  
3. Nota corta (en chat o archivo personal) con: tu rol, tu carpeta, path completo  

## Criterios de aceptación

- [ ] Existe la carpeta del proyecto en tu PC  
- [ ] Cursor muestra `cliente-unity/`, `servidor/`, `inteligencia/`, `expresion/`, `contratos/`, `documentacion/`  
- [ ] Sabes decir tu rol y qué carpeta puedes modificar  
- [ ] Leíste [PROJECT_MAP.md](../../PROJECT_MAP.md)  
- [ ] Leíste [ROLE_OVERVIEW.md](../../ROLE_OVERVIEW.md) (tu columna)  

## Cómo validar el resultado

1. Abre Cursor → File → Open Folder → raíz EmpathIA.  
2. Expande el árbol y señala tu carpeta al mentor.  
3. Resume el flujo del PROJECT_MAP en ≤ 1 minuto.  

## Errores comunes

| Error | Qué hacer |
|-------|-----------|
| Abriste solo una subcarpeta | Abre la **raíz** del monorepo |
| Editas archivos de otro rol “por ayudar” | Para; pide review al owner |
| No encuentras `servidor/` | Puede existir también `backend/` (enlace); usa `servidor/` |

## Qué NO debo hacer

- Instalar Ollama/Whisper/Kokoro en este sprint  
- Cambiar `contratos/`  
- Empezar features de sprints futuros  

## Referencias técnicas

- [STUDENT_HANDBOOK.md](../../STUDENT_HANDBOOK.md)  
- `documentacion/equipo/colaboracion.md`  

## Evidencia de cierre

Mostrar Cursor con el árbol abierto + decir rol y carpeta.
