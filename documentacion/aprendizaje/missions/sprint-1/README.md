# Sprint 1 — Conectar el prototipo

## Objetivo del sprint

Pasar de “mi entorno enciende” a **piezas reales del flujo EmpathIA** conectadas entre roles, sin IA pesada ni lip-sync fino.

## Resultado esperado (equipo)

| Rol | Hecho |
|-----|--------|
| A | Login (+ sesión) contra API de B |
| B | Documentación API usable por A + health/humo |
| C | InferTurn explicado + stub demostrable |
| D | Tabla morphs acordada con A |

## Definition of Done — Sprint 1

- [ ] Checklists A/B/C/D en verde (o “parcial” documentado con bloqueo claro)  
- [ ] Demo A↔B de login intentada en el piloto  
- [ ] Tabla D↔A con al menos 5 filas y columna sí/no empezada  
- [ ] C demostró stub al equipo  
- [ ] Prueba de humo del piloto sigue OK  

## Fuera de alcance

Modelos reales STT/LLM/TTS, WebSockets nativos, MySQL obligatorio, ExpressionPacket animado en runtime, cambios de contrato.
