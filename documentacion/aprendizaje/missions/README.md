# Sistema de misiones — EmpathIA

Las **misiones** descomponen el aprendizaje en unidades verificables.  
No reemplazan el backlog técnico largo: lo hacen ejecutable para estudiantes.

## Cómo usar una misión

1. Lee el **objetivo** y los **criterios de aceptación**.  
2. Confirma **conocimientos previos** (o pide ayuda al mentor).  
3. Trabaja solo en las carpetas de tu rol.  
4. Produce los **entregables**.  
5. Pasa la **checklist** del sprint antes de PR / “terminé”.  
6. En la revisión de sprint, demuestra con evidencia (pantalla, archivo, log).

## IDs

`M{sprint}-{rol}-{slug}`  
Ejemplo: `M0-A-entorno-unity`
