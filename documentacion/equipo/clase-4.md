# Clase 4 — EmpathIA (Sprint 3: voz, nombre y boca)

**Duración:** 3 h 30  
**Sprint:** [Sprint 3](../aprendizaje/missions/sprint-3/)

## Meta

> Cerrar el circuito: el estudiante **oye** la respuesta y **ve** 1 morph; C recibe el nombre preferido; STT deja de ser solo Unity.

## Reloj

| Bloque | Tiempo | Qué |
|--------|--------|-----|
| 1. Pull + demo Sprint 2 | 0:00–0:30 | Un turno con `reply_text` (si aún no se hizo) |
| 2. Mapa del circuito | 0:30–0:45 | Voz + nombre + boca; B y C en el mismo PC |
| 3. 1:1 B→C→A→D | 0:45–1:30 | Abrir M3 + prompt |
| 4. Trabajo | 1:30–2:40 | Codificar / documentar |
| 5. Parejas B↔C, A↔D, A↔B | 2:40–3:10 | Integrar |
| 6. Demo circuito | 3:10–3:30 | TTS audible + morph o bloqueo |

## Éxito al cierre

Un turno en el piloto (o Meet) con **audio de respuesta** y acuerdo de 1 morph.
